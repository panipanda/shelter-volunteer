# Fonts

The `ubuntu-mono-*.woff2` files are Ubuntu Mono (regular and bold), split by
script subset (latin, latin-ext, cyrillic, cyrillic-ext) as served by Google Fonts.

- Designer: Dalton Maag

- Licensed under the Ubuntu Font Licence 1.0. The full text is in
  [UFL.txt](UFL.txt) and must stay next to the font files.

Source: https://fonts.google.com/specimen/Ubuntu+Mono
