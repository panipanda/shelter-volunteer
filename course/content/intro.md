# Как устроен курс и проект

В этом уроке вы познакомитесь с сайтом, на котором построен весь курс, получите его карту и (по желанию) запустите у себя. Дальше каждое понятие будет привязано к конкретному файлу этой карты.

## Что за сайт

**Pro Anima** — сайт для волонтёров приюта для кошек в Белграде. Он отвечает на вопросы, которые волонтёры задавали в чатах снова и снова: какие кошки ищут дом, когда ближайший выезд, как к нему присоединиться, что нужно знать новичку.

Что умеет сайт:

- Каталог кошек и собак с карточками и страницами животных: фото, возраст, здоровье, статус «ищет дом».
- Гайд волонтёра, ближайший выезд (считается по расписанию: среда 9:00 и суббота 10:00), страница «Как помочь».
- **Три языка**: русский (по умолчанию), английский и сербский (латиница). Адрес начинается с языка: `/ru/cats`, `/en/cats`.
- Светлая и тёмная тема, доступность с клавиатуры и скринридеров.
- **Админка** (`/admin`): волонтёры сами добавляют животных и фото, редактируют тексты страниц, собирают новые разделы и меню. Включается только вместе с базой данных.

Сайт живёт в бесплатных тарифах: хостинг Render (512 МБ памяти на всё) и база Neon (засыпает через пять минут простоя). Эти ограничения сильно повлияли на архитектуру, и мы не раз к ним вернёмся.

:::note Почему именно этот проект
Он достаточно мал, чтобы прочитать его целиком, и достаточно реален, чтобы в нём были настоящие задачи: многоязычность, права доступа, загрузка файлов, кэш, тесты, деплой, доступность. Учебные приложения про «список дел» этого не дают.
:::

## Карта проекта

Код лежит в `src/main/kotlin/org/proanima/shelter/`. Папки соответствуют слоям. Эту таблицу полезно держать перед глазами весь курс.

| `service/` | Правила: что показывать, как считать возраст и следующий выезд, как строить меню | [Алгоритмы](lesson:a2-algorithms) |

## Путь одного запроса

Когда вы открываете `/ru/cats/felix`, происходит вот что:

```text
браузер
  └─ GET /ru/cats/felix
Netty (сервер)              принимает соединение
  └─ плагины Ktor           сжатие, заголовки кэша, обработка ошибок
Routing                     находит get("/cats/{slug}") внутри route("/ru")
  └─ CatRoutes              достаёт slug и язык
CatService                  getCatBySlug("felix"): только опубликованные
  └─ CatRepository          JSON-файл или PostgreSQL (маршрут об этом не знает)
views/CatViews.kt           превращает Cat в HTML на Kotlin
  └─ respondPage            добавляет меню, типографику, отправляет текст
браузер                     получает готовую страницу
```

Запомните эту схему: **маршрут не знает, где хранятся данные, а страница не знает, откуда пришли данные**. Это и есть архитектура проекта в одном предложении.

## Стек

| Что | Чем | Зачем |
|---|---|---|
| Язык | Kotlin 2.0.21, JVM 21 | Краткий, безопасный к `null`, хорошие инструменты |
| Сервер | Ktor 2.3 на Netty | Лёгкий, расширяется плагинами, удобно тестируется |
| HTML | kotlinx.html | Страницы как код: типобезопасно, без шаблонизатора |
| Данные | kotlinx.serialization, PostgreSQL (Neon), HikariCP | JSON-документы в таблицах, пул соединений |
| Тесты | kotlin.test, `testApplication`, H2 в режиме PostgreSQL | Быстро и без внешних серверов |
| Фронтенд | Чистые CSS и JS, без сборки и фреймворков | Сайт — это текст; скрипты только улучшают |
| Деплой | Docker, Render, GitHub Actions | Упавший тест не пускает сборку на продакшен |

## Запуск у себя (по желанию)

Нужны Git и JDK 21 (проверьте `java -version`). Остальное подтянет Gradle Wrapper из репозитория.

```bash
git clone https://github.com/panipanda/shelter-volunteer.git
cd shelter-volunteer
./gradlew test        # on Windows: .\gradlew.bat test
./gradlew run         # the site is at http://localhost:8080/ru
```

Чтобы посмотреть админку без настройки базы, есть специальная задача:

```bash
./gradlew devAdmin    # http://localhost:8095/admin, password: dev-password-123
```

Она поднимает сайт с базой в памяти (H2), начальными данными из папки `data/` и паролем для разработки. Всё сбрасывается при остановке.

:::tip Если ничего устанавливать не хочется
Вы можете пройти весь курс только в браузере: Kotlin-примеры запускаются в редакторах на страницах, а файлы проекта открываются по ссылкам на GitHub.
:::

## Как работать с уроками

Блоки с пометкой **Live coding** идут пошагово: нажимайте «Дальше» и повторяйте шаги в соседнем окне. Если хотите увидеть всё сразу, есть кнопка «Показать все шаги».

Попробуйте редактор прямо сейчас: измените имя приюта и нажмите кнопку запуска. Редактор подключается к серверу JetBrains, поэтому ему нужен интернет.

```run
fun main() {
    val shelter = "Pro Anima"
    println("Hello, $shelter!")
}
```

```output
Hello, Pro Anima!
```

Если редактор не загрузился (нет сети), код по-прежнему виден, его можно скопировать кнопкой в углу блока.

## Практика

::::task Запустите сайт или разберите схему
Выберите вариант по настроению.

**Вариант А.** Выполните `./gradlew run` и откройте `http://localhost:8080/ru/cats`. Переключите язык и тему, затем измените адрес на `/en/cats/felix`.

**Вариант Б (без установки).** Откройте на GitHub файл [Application.kt](repo:src/main/kotlin/org/proanima/shelter/Application.kt) и найдите функцию `configureRoutes`. Выпишите, какие `*Routes`-функции подключаются внутри `route("/${locale.code}")`.

:::solution
В `configureRoutes` внутри цикла по `AppLocale.entries` подключаются: `homeRoutes`, `catRoutes`, `dogRoutes`, `visitRoutes`, `guideRoutes`, `helpRoutes`, `sectionRoutes`. То есть **все страницы сайта существуют под тремя языками сразу**: один и тот же код повторяется для `/ru`, `/en` и `/sr`.

Рядом, вне цикла, подключены то, что от языка не зависит: `healthRoutes` (проверка живости), админка (если включена), картинки, иконки, шрифты, стили и скрипты.
:::

:::quiz Проверка: что мы разбираем
Q: Почему сайт хранит данные кошек в PostgreSQL, а не в файле `data/cats.json` на сервере?
- [ ] Файлы JSON не умеют хранить русские буквы.
- [x] Бесплатный тариф хостинга стирает диск при каждом деплое, а админка должна сохранять правки между деплоями.
- [ ] PostgreSQL быстрее читает файлы.
- [ ] Так требует Ktor.
E: Правки, сделанные волонтёрами через админку, нельзя хранить на диске, который очищается при деплое. Поэтому появилась внешняя база. Файлы остались режимом по умолчанию для локального запуска и тестов.

Q: Что из перечисленного НЕ знает маршрут `GET /ru/cats/{slug}` о данных?
- [x] Лежат ли кошки в файле или в базе.
- [ ] Что нужно вернуть 404, если кошка не найдена.
- [ ] Какой язык у страницы.
- [ ] Какой сервис вызвать.
E: Маршрут зависит от `CatService`, а сервис от интерфейса `CatRepository`. Какая именно реализация подключена, решает `Application.kt`.

Q: В каком порядке данные проходят через слои при показе страницы?
- [ ] views → routes → repository → service
- [x] routes → service → repository, затем результат уходит во views
- [ ] repository → routes → service
- [ ] service → views → routes → repository
E: Маршрут принимает запрос, сервис применяет правила, репозиторий достаёт данные. Готовые данные отдаются в функцию-представление, которая строит HTML.

Q: Зачем в проекте нет JavaScript-фреймворка?
- [ ] Автор не любит фреймворки.
- [x] Сайт состоит в основном из текста и фото; серверной вёрстки хватает, а скрипты лишь добавляют удобство (тема, меню, галерея).
- [ ] Kotlin не умеет работать с JavaScript.
- [ ] Фреймворки запрещены на бесплатном хостинге.
E: Это осознанное решение: меньше кода, быстрее загрузка, сайт работает даже при заблокированных скриптах. Подробнее в уроке про [JavaScript](lesson:w4-js).
:::
